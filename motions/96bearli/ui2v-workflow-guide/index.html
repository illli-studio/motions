How the UI2V flow works

publish motion like a package · install animation like a dependency

›
›
1

Create

HyperFrames

Author & preview a motion composition, then export a package folder.
index.html + registry-item.json

2

Publish

ui2v motion publish

Log in, then publish the folder with a semver version to the registry.
ui2v login · ui2v publish ./my-motion --version 1.0.0

3

Install

npx @ui2v/cli

Anyone installs it as a dependency.
npx @ui2v/cli@latest install <slug>
