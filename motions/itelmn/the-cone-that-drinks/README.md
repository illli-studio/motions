# 松果遇水，为什么会合拢？
28.8s /1920×1080/30fps 原创知识动画。一个问题、一次鳞片结构放大、一次干湿回归对照。
Editable entry index.html + film.js. Native deterministic Canvas projection of actualXYZ polygon meshes; no prerendered whole-frame assets. GSAP timeline drives the scene and Hyperframes drives audio. Change geometry/text/timing in film.js; audio.py generates original score but is not required by runtime.
Official tooling: HYPERFRAMES_NO_TELEMETRY=1 hyperframes preview; hyperframes check --json; hyperframes render --quality high --workers 2 --strict.
Scientific references and limitations in SOURCES.md. All original work MIT-0; see THIRD_PARTY.md for dependencies.
