# 降噪，不等于静音
30 秒中文知识动画，1920×1080、30fps。原创可播放几何耳罩剖面与二维声压图共同解释：麦克风检测 → 反相控制 → 耳边叠加 → 时间误差限制 → 被动隔音。

## 编辑与播放
`film.js` 是确定性的时间驱动场景；修改每个场景函数即可编辑图形、文字和运动。`index.html` 暴露暂停的 GSAP 时间线 `window.__timelines.anc`，供 Hyperframes 寻帧和播放。`preview.html` 提供本地播放、暂停与时间跳转。使用 HTTP 服务预览，资源均在本目录，不依赖外部 CDN。

源工程附带 `render.cjs`，使用 `@napi-rs/canvas` 和 FFmpeg 将同一场景代码独立导出为 MP4。此次 MP4 是该独立导出路径的产物；没有将受阻的官方 Hyperframes CLI 检查或导出声称为通过。平台包无整段视频、逐帧图片或 Base64 画面。

## 科学边界
声压曲线是同一位置随时间的示意，不是空间中两束声音相撞。低/高频对比使用同一归一化时间误差、相同声压比例，残余按真实相加计算。声音是原创教学音效，不是耳机实测，也不是可供听音比较的降噪实验。实际效果取决于系统、频率、密封和佩戴。单外侧麦克风仅为简化前馈结构，不代表所有产品。无听力保护承诺。
