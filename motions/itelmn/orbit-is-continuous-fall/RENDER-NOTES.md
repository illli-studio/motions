# Render route and limitations
Browser-native index.html → paused GSAP timeline → OrbitScience.render(Canvas2D,t). Same deterministic JavaScript exports native1920×1080 frames through @napi-rs/canvas and FFmpeg H.264/AAC. This is not a pre-rendered video wrapper. Runtime uses actual XYZ meshes and projection, not a Blender source file.

Official HyperFrames CLI telemetry previously encountered permission denial. No official lint/inspect/render/doctor run is claimed here and no denied telemetry route was retried. Independent export, fulldecode, media measurements and observed browser playback are separately documented.

No narration. Chinese vector annotations and causal comparison carry the explanation; original non-diegetic score assists pacing. Audio decoding and loudness measurements do not imply subjective listening.
