# Marea

A faithful package of the existing Papermotion example **sea**. The visual and sound content comes from the upstream example; it was not newly authored for this upload. The MP4 was rendered from the repository's example source and transcoded to 1280×720 H.264/AAC to fit UI2V's per-file size limit. This package uses a HyperFrames video clip wrapper; the original animation engine is Papermotion, not HyperFrames, and the animation is embedded as rendered video rather than editable scene code.
