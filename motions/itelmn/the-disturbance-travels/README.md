# 声音到了，空气也一路跑来了吗？
26秒 / 原生1920×1080 / 原创有声音轨 / 可编辑Hyperframes HTML。

扬声器振膜往返推挤空气，疏密图样向前传播。跟踪一个黄色空气体积元，并用二维放大框观察它在平衡位置附近往返，解释局部运动不等于随波长途迁移。

## 原生工程
index.html 为Hyperframes入口；film.js 包含实际XYZ网格扬声器、振膜、空气体积元和接收端，Canvas对原生几何投影着色，时间完全确定。GSAP暂停时间线注册至window.__timelines。发布包只含代码、字体、原创建构的音轨和许可，不含整片视频或逐帧图像。

## 编辑与导出
修改film.js 中几何、文字和时间参数；官方hyperframes preview播放、render导出。源码包中的render.cjs仅做静帧和短动态开发检查；正式MP4由官方Hyperframes导出。无需Blender或Python运行平台工程。

## 科学边界
小振幅、理想平面纵波，无背景气流；球是含许多分子的空气体积元，不是单个分子，忽略热运动。已建立的连续波，不演示起始波前或测量传播速度。疏密由位移场局部梯度得出，几何/振动放慢非等比例；音乐为听觉示意，不是图中频率的录音。来源见SOURCES.md。
