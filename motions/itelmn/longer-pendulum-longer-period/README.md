# 长摆，为什么摆得慢？
28 秒原创知识科普：同一重力环境、相同小摆角释放两个理想单摆，以完整归位计数展示摆长 4 倍时周期约为 2 倍。最后以角加速度而非所有瞬时线速度解释“慢”。

原生 1920×1080、30 fps；原创声景，无旁白。忽略阻力、轻且不可伸长的摆线、质点摆球、小角度近似；几何示意，不作真实实验数据。

在 Hyperframes 中打开 index.html。独立本地预览运行 python preview-server.py，然后打开 http://127.0.0.1:8797/preview.html；使用播放/暂停和时间按钮。编辑 film.js、HTML 与 assets/score.mp3。渲染路径与检查边界见 RENDER-NOTES.md，一手来源见 SOURCES.md。
