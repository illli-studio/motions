# 月亮为什么会变弯？
29.5 秒、1920×1080 的原创中文知识科普。以半球受光和地球观察视角解释月相，并单独区分特殊对齐下的月食。

## 编辑与播放
index.html 是 HyperFrames 原生入口；film.js 的确定性 render(context,time) 生成真实球面网格、光照与轨道位置图；不是预渲染视频。修改片中标签、参数、时长后同步更新 HTML/manifest。preview.html 是可暂停、拖动的本地浏览器预览，不使用视频贴片。

## 科学边界
方向光、球形天体、圆轨道为简化；大小、距离、速度不成比例。普通月相的空间图是位置投影且省略遮挡，不模拟月食；月食专用镜头用影区与月球几何交集说明特殊对齐。地球视图北向朝上，实际地平线朝向随观测地与时刻变化。地形完全原创示意，不是月面地图。约半球受太阳照亮，月食为例外。
