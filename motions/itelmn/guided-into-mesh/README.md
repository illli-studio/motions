# 拉链头为什么能把两排齿合上？
28.5秒 / 原生1920×1080 / 原创声轨 / 可编辑Hyperframes HTML。

问题：为什么拉一下拉链头，两排齿就合上？
Y形导槽引导链齿，交错的齿头形成配合；反向移动时，两列齿沿分叉路径分离。用三维织带、滑块空导槽与放大的啮合关系讲清楚“导向”和“啮合”不是同一件事。

原生运行：index.html 引入本地GSAP、film.js、字体及score.mp3，确定性时间驱动；实际XYZ挤出几何由Canvas投影/深度排序。不包含整片视频、逐帧图片、外网脚本或Base64。不是Blender/Python播放包装。
编辑：film.js修改形状/文字/镜头，官方hyperframes preview和render。源包audio.py用于重新生成原创声轨，render.cjs仅开发静帧/短动态检查；正式MP4由官方CLI导出。

边界：结构与运动简化示意，非制造尺寸。齿头配合放大图不是装配轨迹；隐藏接合区不作为精密机械仿真。真实拉链结构、材料与齿形存在差异；不展示强度或承载数据。音效是编辑性动作提示，不是实测录音。来源详见SOURCES.md。
