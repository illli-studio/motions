# 路牌为什么会把车灯的光送回来？
原创知识动画，29.4秒 / 1920×1080 / 30fps / 有声。
一种路牌反光膜使用角锥微棱镜。三面两两垂直的反射面会让有效光路经历三次反射，反转传播方向；理想出射与入射平行反向但通常侧向错开。真实材料把光返回光源附近的一个光锥，所以靠近车灯的观察者更容易看见明亮路牌。
边界：本片只讲微棱镜型，另有玻璃微珠型。空心三面镜是方向解释模型，忽略折射与损耗；并非所有入射角均有效，演示路径需命中三个面。所有尺寸、光速和光锥示意，不用于道路设计或性能预测。
一手出处与具体对应见 SOURCES.md (3M,Thorlabs,NASA)。没有复制资料图。
